Informe — Prueba API REST con Postman

¿Qué se hizo?
Se probó una API REST de libros desarrollada en Spring Boot usando Postman,
verificando las operaciones POST, GET, PUT y DELETE sobre el endpoint `/api/v1/libros`.

Problemas encontrados
- La URL tenía un typo: `/ap1/v1/libros` en vez de `/api/v1/libros`, causando error 404.

Resultado
Se insertaron 5 libros correctamente y todas las operaciones CRUD funcionaron sin problemas.
Los cambios fueron subidos a GitHub exitosamente.
